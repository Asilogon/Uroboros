# Commit message convention (Uroboros)

Формат сообщения коммита:

```
[X.X.X] Суть изменения

<подробное описание: что сделано, зачем, какие файлы затронуты>

Version: X.X.X
Files:
- path/to/file1
- path/to/file2
```

Правила:

1. **Заголовок** — строго `[X.X.X] Суть изменения`.
   - `X.X.X` — новая версия программы (берётся из `VERSION`).
   - «Суть изменения» — короткое человекочитаемое описание (до 72 символов), без точки в конце.
   - Пример: `[0.0.2] Веб-доступ и иконка планеты для агентов`
2. **Пустая строка** после заголовка.
3. **Тело** — подробное описание: что сделано, зачем, какие тесты пройдены.
4. **Version:** и **Files:** — служебный блок в конце.
5. Один коммит = одна законченная задача + наращивание версии.
6. Коммит делается сразу после успешных тестов, до отправки финального ответа пользователю.

## Как создаётся коммит

Скрипт `commit_changes.py` читает `VERSION` и собирает сообщение в этом формате.
